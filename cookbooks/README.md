# Cookbooks

Task-oriented, runnable recipes for this project. Each cookbook is a self-contained folder with a README and a runnable notebook.

- [Flask Integration Guide for AgentEval - Testing Flask Agents](./flask-agenteval-testing-guide/README.md): Complete guide to testing Flask-based AI agents with AgentEval. Learn how to instrument Flask routes, wrap tools, assert on behavior, and run reliability tests.
